# UNP_PROJECT_BI_WITH_POWER_BI_COMPANY_FINANCIALS_DATA

This project, conducted in collaboration with UNP, involved developing a Company Financials Dashboard to analyze financial performance across multiple dimensions. The process included understanding the data, transforming it (if needed), calculating key metrics, and creating a visual dashboard for insights. The analysis covered sales trends, profitability, discount patterns, and pricing strategies, revealing seasonal sales spikes (October), high sales in the USA but greater profitability in France and Germany, and disproportionate discounts in Mexico. Additionally, Amarilla emerged as a high-margin product despite lower sales. Key recommendations include optimizing discounts, focusing on high-margin products, expanding in top-performing markets, and leveraging seasonal trends. This structured, data-driven approach helps enhance profitability and optimize financial strategies for better decision-making.
